\# Hospital Appointment Management System



\## Project Description

The Hospital Appointment Management System is a web-based project designed to manage hospital-related activities efficiently.



\## Features

\- Patient Registration

\- Doctor Management

\- Appointment Scheduling

\- Appointment History



\## Project Modules

1\. Patient Registration

2\. Doctor Management

3\. Appointment Scheduling

4\. Appointment History
